# ⛩️ Fonts Directory

This widget collection uses the **Okami** brush font for its Japanese calligraphy aesthetic.

---

### Font Licensing & Download

**Font Name**: Okami  
**Designer**: Mehmet Reha Tugcu ([Tugcu Design Co.](https://www.behance.net/tu29c0))  
**License**: Free for Personal Use  

Due to licensing terms, the font binary is not redistributed directly in this repository.

#### Where to Download:
You can download the font for free (personal use) from:
- [DaFont - Okami](https://www.dafont.com/okami.font)
- [Behance - Okami Font](https://www.behance.net/gallery/42792625/Okami-Font)

---

### Installation

1. Download the ZIP file from one of the links above and extract it.
2. Place the `Okami.otf` file directly into this directory:
   ```text
   conky-widgets/fonts/Okami.otf
   ```
3. Run the installer from the repository root:
   ```bash
   ./install.sh
   ```
   The installer will automatically register the font into `~/.local/share/fonts/` and refresh your system font cache.
